# Turntable audio

Drop the final MP3 files here using these exact filenames:

- `instant-crush.mp3`
- `avunu-nijam.mp3`
- `the-way-i-am.mp3`
- `in-the-end.mp3`

The matching track plays when its vinyl is on the platter and the tonearm is
lowered. Lifting the tonearm pauses playback. Loading another vinyl switches to
that record's audio and starts it from the beginning when the tonearm is lowered.
