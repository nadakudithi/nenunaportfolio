# Section media

Each page section owns its media folder. Replace a file in place, keeping the
same filename and extension, to update that section without touching the code.

- `hero/` — name artwork and navigation logo
- `intro/` — opening portrait
- `gallery/` — gallery phone image and cassette artwork
- `work/` — work-section phone image
- `about/` — about collage media
- `contact/` — future record covers and audio
- `audio/` — turntable MP3 tracks

The copies of `hand-phone.png` are intentionally separate. Replacing the image
in one folder affects only that section.
